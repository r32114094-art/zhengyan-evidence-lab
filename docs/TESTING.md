## 规则测试覆盖

1. 2024 原始元值计算、83.42%增量占比和有边界结论。
2. 2025 利润下降导致前提失效，不算正向贡献率。
3. 90%严格阈值下结论降级。
4. 未覆盖公司不套用比亚迪数据。
5. 文本年份与选择期间冲突。
6. 当前/季度命题范围拦截。
7. 无关与否定表述不进入默认结果。
8. 跨公司比较证据不足。
9. 估值序列缺失保持未知。
10. 产业链相关性不升级为因果。
11. 主命题和追问的合规边界。
12. 未识别追问不创造事实。
13. 引用ID、页码和哈希合法。
14. 2023可比毛利口径与百分点计算。
15. 人民币元与零分母边界。
16. 畸形请求、超长输入、无效阈值和年度。
17. 用户命题中包含指令式文本时不执行该指令。

## 浏览器检查覆盖

澄清修订并运行、反向证据筛选、原文页码链接、追问、保存后刷新恢复、JSON导出、年度比较导致结论变化、验证服务503、报错后恢复、合规追问、原文超时、未知公司、任意URL拒绝、跨Origin拒绝、无效请求拒绝、移动端导航、无未捕获浏览器错误。

其中503与上游超时使用Playwright路由**故障注入**，证明的是应用的错误处理，不证明第三方接口稳定性；演示视频也明确标注了这一点。真实上游成功另有独立记录，不与模拟混用。

## 已发现并修复

- “没有盈利改善”被正向规则误识别：增加否定句范围限制并通过回归。
- Worker 不支持 `redirect: error`：改为 `manual`，真实上游调用复测成功。
- API JSON返回值类型未知：增加显式类型边界并通过类型检查。

## 复现

```bash
npm ci
npm test
npm run typecheck
npm run build
npm run dev
# 另一个终端中，安装或使用已有Playwright环境后：
node tests/e2e.mjs
```

可用 `APP_URL`、`PLAYWRIGHT_MODULE_PATH`、`PLAYWRIGHT_BROWSER_EXECUTABLE_PATH` 适配本机环境。脚本自动创建 `test-results/`，浏览器测试需能够访问开发服务器；默认Playwright Chromium需先安装。
