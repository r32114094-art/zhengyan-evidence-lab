# AI 使用与验证记录

## 实现边界

本项目由 Codex 协助设计、编码、资料定位、文档与测试。用户最初选择暂不接模型，随后要求“示例接本地部署的小模型，README说明复现时自己接模型”；本次已新增真实 Ollama 接入，不使用 OpenAI API。

示例模型为 Qwen2.5 3B，通过本机 Ollama `/api/chat` 推理。初始模板拆解、财务计算、期间检查与结论等级由程序确定；模型负责证据解读、进一步的可验证子问题和追问。没有声称模型能检索任意公司或自动解析全份 PDF。

## 已做的核验

- 原始财报实际下载、定位页码并计算文件哈希；数值、单位与重分类口径独立复核。
- 模型只接收服务端重建的证据，不信任浏览器提交的财务事实或证据编号。
- Ollama 使用结构化 JSON、temperature=0、固定 seed；这些只增强可重复性，不保证事实正确。
- 检查模型名、完成状态、JSON字段、证据编号和输出范围；超时、不可达、截断与无效输出明确降级，保留规则结果。
- 保存实际模型名、生成时间、提示版本、耗时和引用，任务恢复不会重新编造历史回答。
- `docs/examples/local-model-runs.json` 是真实本地调用记录，包含请求、响应与模型摘要；不是在线服务承诺，也不是模拟返回。

## 实测发现与调整

1. Qwen2.5 1.5B 曾混淆补助金额和毛利率口径，收紧提示后又出现重复文字直到截断。没有将这些失败内容作为成功示例交付。
2. 调整为 Qwen2.5 3B，并对模型输入做定性化处理，避免它直接复述待验证命题为事实。数字由财务证据卡展示，模型解读出现阿拉伯数字时拒绝该输出。
3. 增加不同计量口径混用的回归检查；这属于有限规则，不能穷尽语义错误。
4. 归因待验证时要求模型保留“不能确认主营因果”，模型不参与修改确定性结论。
5. 旧版导出中的“未接模型”说明改为以实际 `ai` 状态为准，避免混淆规则与模型来源。

## 不可声称的结果

引用存在不保证引用准确，结构校验不等于内容可靠。真实小样本运行只证明接通、结果展示及部分边界工作；没有测量通用幻觉率、任务完成率、投资回报或全面的抗提示注入能力。自动合规关键词不是完整合规审查。没有在线共享模型服务或长期负载验收。

后续需要独立标注集评估命题理解、证据引用准确性、财务语义、拒答和对抗输入，不能把单元测试通过率宣称为模型准确率。
