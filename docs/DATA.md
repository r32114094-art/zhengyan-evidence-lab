## 不可越过的推断

1. 扣非增量占比高，不等于主营因果已识别；不存在完整利润桥时只能部分支持。
2. 现金流下降是盈利质量的反向线索，不能直接证明利润虚假或主营恶化。
3. 从21.02%到22.31%是1.29个百分点，不是1.29%的相对增长。
4. 2024扣非并未剔除所有补助；全部补助与非经常性补助不能互换。
5. 同一报告在不同网站转载不能增加独立证据数量。
6. 历史年度盈利变化不支持当前估值或买卖建议。已发现2026半年报但未分析。
