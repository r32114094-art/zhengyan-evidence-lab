# 证研 / Zhengyan

把投资判断拆成可以核验的问题，以原始财报组织支持、反向和无法验证的证据，并记录什么信息会改变结论。

**交付状态：已实现 Ollama 本地小模型接入。示例使用 Qwen2.5 3B：模型解读证据、提出可验证子问题并回答追问；财务数值与结论等级仍由程序计算。复现者必须自行部署并连接模型，仓库不附带模型权重、密钥或共享推理服务。**

- Web 产品：https://zhengyan-evidence-lab.barry1231.chatgpt.site
- 源代码：https://github.com/r32114094-art/zhengyan-evidence-lab
- 默认网站与 GitHub 仓库均为私有；对外评审前需设置可访问权限。
- 原始资料：公开公司年报；不依赖扶摇 / iFinD 凭证。
- 演示：交付包 `证研-产品演示.mp4`（浏览器实录，约两分钟，带字幕）。

## 用户与核心问题

面向需要核对投资假设的个人研究者和初级分析师。常见问题不是“没有一段总结”，而是结论缺少边界：没有统一时间和口径，支持材料比反向材料更容易被选中，代理指标被误写成因果，后续证据变化后原判断仍被沿用。

本产品围绕一项研究展开：**提出命题 → 澄清、修订 → 验证 → 查看证据与冲突 → 比较新年度 → 追问 → 保存或导出**。

## 快速运行

需要 Node.js 22.18+（本次使用 26.5.0）、npm、[Ollama](https://ollama.com/download) 与首次下载模型的网络。本机示例无需 OpenAI API 密钥。

### 1. 自行启动本地模型

安装 Ollama（macOS 可用 `brew install ollama`），在一个终端启动服务：

```bash
OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NO_CLOUD=1 ollama serve
```

如果 Ollama 应用已经运行，不要重复启动。另开终端下载示例模型（约 1.9 GB）：

```bash
ollama pull qwen2.5:3b
ollama list
```

### 2. 配置自己的模型连接

```bash
npm ci
cp .dev.vars.example .dev.vars
npm run dev
```

`.dev.vars` 是仅本机使用的服务端配置，已被 Git 忽略。默认内容如下；使用其他模型时，把名称改为 `ollama list` 中的完整名称，修改后重启开发服务器：

```dotenv
EVIDENCE_MODEL_PROVIDER=ollama
EVIDENCE_MODEL_BASE_URL=http://127.0.0.1:11434
EVIDENCE_MODEL_NAME=qwen2.5:3b
EVIDENCE_MODEL_TIMEOUT_MS=60000
```

打开终端显示的地址（默认 `http://localhost:5173`），右上角应显示“模型已连接”。完成默认案例后，“模型证据解读”会显示实际模型名、耗时、证据引用和待验证问题；追问也会调用模型。连接状态可以通过 `/api/model/status` 检查；仅显示连接成功不等于单次推理输出通过验证。

**复现时请自己接模型。** 不复制配置也能运行规则验证，但不会产生模型解读。服务停止、超时或输出未通过校验时会明确提示降级，不能把规则结果当成模型生成。

### 3. 本地与云端部署的区别

线上示例运行于 Cloudflare Workers，无法访问你电脑的 `127.0.0.1`。当前线上部署没有配置模型服务，保留规则验证及明确的未连接提示。视频中的模型调用来自本地运行环境。

部署者若需要云端模型能力，须自行提供服务端可访问的 HTTPS Ollama 兼容服务，并在运行环境配置上述变量；可选 `EVIDENCE_MODEL_API_KEY` 用于带 Bearer 认证的自有网关。不要将密钥写入前端，也不要直接公开没有认证的 Ollama 端口。直接在本机复现无需远程服务。

```bash
npm test
npm run typecheck
npm run build
npm start
```

`npm test` 为研究规则及模型协议/校验测试（模拟接口，不要求本地模型）；`npm run build` 生成 Cloudflare Worker 部署产物。`npm start` 启动构建后的本地 Worker。保留 Sites 的构建集成；若部署到新的 Sites 项目，必须使用新的项目身份替换 `.openai/hosting.json`，不要向本仓库原项目直接发布。

浏览器回归脚本见 `tests/e2e.mjs`，通过 `PLAYWRIGHT_MODULE_PATH` 指定已安装 Playwright 模块，通过 `PLAYWRIGHT_BROWSER_EXECUTABLE_PATH` 指定 Chromium/Chrome；默认使用 `playwright` 包和其 Chromium。测试前启动开发服务器，并设置 `APP_URL`（缺省为 http://localhost:5173）。

## 建议体验路径（两分钟）

1. 使用默认命题：“比亚迪2024年盈利改善主要来自主营业务，而非一次性收益。”
2. 点击“拆解命题”，把主要贡献阈值修订为 70%，确认年度口径后验证。
3. 查看部分支持的结论：扣非利润增量解释约 83.42% 的归母净利增量；不是主营因果的充分证明。
4. 筛选反向证据：经营现金流下降 21.37%。打开来源，定位至年报 PDF 第 11 页。
5. 查看模型证据解读与可验证子问题，再追问“扣非等于主营吗？”。核对引用与回答是否一致。
6. 打开年度比较并用 2025 年重验：归母和扣非利润下降，盈利改善前提被反对。
7. 添加备注，保存研究；刷新后在研究任务中恢复。导出 JSON 包含命题、证据、来源和备注。
8. 原始材料库可以重新下载固定白名单中的原文并校验 SHA-256；异常时保留历史快照并报错。

## 设计与实现

视觉方向是安静的研究台：纸白底、深绿色侧栏、低饱和证据状态色。证据不以“多数票”生成结论，未知不隐藏。使用覆盖度而不是无依据的置信百分比。桌面和移动端均可操作。

- `components/research-app.tsx`：研究流程、来源详情、对比、任务与导出。
- `lib/research.ts`：输入范围、规则拆解、财务计算、证据构建与有界追问。
- `data/financials.json`：已核验原始金额、币种、期间、来源家族、页码和文件指纹。
- `lib/model.ts`：Ollama 结构化输出、证据约束、超时和失败降级。
- `app/api/research/route.ts`：研究规则计算与真实模型证据解读。
- `app/api/followup/route.ts`：服务端重建可信证据后调用模型回答追问。
- `app/api/model/status/route.ts`：查询模型连接与下载状态。
- `app/api/sources/route.ts`：固定来源下载、超时/大小限制与内容哈希验证。
- `tests/`：规则回归与浏览器测试。
- `docs/`：AI 使用记录、测试说明、数据说明与演示脚本。

技术栈：React + TypeScript + Vinext/Vite，运行于 Cloudflare Workers。任务持久化使用浏览器 localStorage；当前不需要数据库。个人研究结果不写入共享服务器。

## AI 的角色

开发阶段使用 Codex 辅助需求拆解、代码实现、资料定位与文档整理，并将财务数字逐项回到原始 PDF 校验。运行阶段通过服务端 `/api/chat` 调用本地 Ollama；没有浏览器直连模型或 OpenAI API 调用。

初始命题范围、模板拆解、财务比率与结论等级由确定性规则处理。模型接收服务端整理的证据解释和限制，生成 `assessment / evidence_ids / questions / limitations`。它用于证据解读、进一步拆解验证问题及研究追问，不执行交易、不自动搜索额外事实，也不能修改财务结论等级。

代码检查结构完整性、已知证据 ID、输出完成状态、部分交易建议和明显口径混淆；定量数值仅由财务卡展示，模型自然语言中出现阿拉伯数字会触发降级。模型输出保留模型名、生成时间、提示版本和耗时；保存/恢复会保留当时的实际回答，而不是重新生成。

**引用存在不代表引用准确，格式验证不等于事实验证。** 小模型仍可能复述命题或混淆财务概念。实际发现的失败、修复与运行样例见 `docs/AI_USAGE.md` 和 `docs/examples/local-model-runs.json`；研究者仍需核对模型解释与原文，不将小样本实测宣称为通用准确率。

## 数据与证据边界

当前仅覆盖比亚迪 2023–2025 完整年度报告，研究期间可选 2024 或 2025。2023 是比较基期。已知 2026 半年报存在，但未纳入本版；不得称本版数据为最新财报或当前投资观点。

数据来自公司原始披露，托管于巨潮资讯、港交所和深交所。四份文件属于三个年度证据家族；2024 巨潮与港交所为同一报告的转载。所有财务证据仍以同一发行人披露为基础，不能声称获得第三方独立验证。

- 金额底层统一人民币元，展示为亿元；附注中的千元需要乘 1,000。
- 2024 归母净利 402.54 亿元、扣非 369.83 亿元、经营现金流 1,334.54 亿元。
- 增量占比 = (36,982,887,000 − 28,462,432,000) / (40,254,346,000 − 30,040,811,000) = 83.42%。
- 归母净利没有正增量时，不计算正向增长贡献率。
- 2023 汽车相关毛利率使用 2024 年报重分类后的 21.02%，与 2024 年的 22.31% 比较，增加 1.29 **个百分点**。
- 扣非不等于主营，也不等于剔除所有补助。2024 全部计入损益补助约 106.60 亿元，列入非经常性损益的补助约 37.81 亿元，二者口径不同。

页码与原文链接见数据文件、产品来源面板和 `docs/DATA.md`。快照是人工核对的结构化提取，不是在线自动抽取。核验原文状态只检查同一 PDF 是否变化，不搜索新的披露。

## 错误与安全

请求长度、参数类型、期间和阈值有校验；其他公司、季度、当前时点和未覆盖表述不能套用样例证据。规则语言理解能力有限，不支持任意自然语言命题。

来源接口只接受固定来源 ID，不接受用户 URL；禁止跟随重定向，限制 18 秒及 24MB；HTTP、非 PDF、哈希变化与网络超时分别处理。浏览器请求校验 Origin；React 转义用户文本。尚未针对公共高并发场景部署全局配额或防滥用系统，因此默认私有。

个人研究备注只在本机浏览器保存，清除浏览器存储会删除任务；无跨设备同步。保存失败会提示导出。来源检查状态为本次会话状态。页面不提供内幕信息、收益保证、个性化仓位或交易指令；关键词边界规则不等于完整合规审查。
