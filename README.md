# 证研 / Zhengyan

把投资判断拆成可以核验的问题，以原始财报组织支持、反向和无法验证的证据，并记录什么信息会改变结论。

**交付状态：可运行的规则验证原型。按用户在 2026-10-19 的明确要求，暂不接入大模型。运行时没有 AI 模型调用，不能将本版宣称为完成了 AI 推理能力的最终参赛作品。**

- Web 产品：https://zhengyan-evidence-lab.barry1231.chatgpt.site
- 源代码：https://github.com/r32114094-art/zhengyan-evidence-lab
- 默认网站与 GitHub 仓库均为私有；对外评审前需设置可访问权限。
- 原始资料：公开公司年报；不依赖扶摇 / iFinD 凭证。
- 演示：交付包 `证研-产品演示.mp4`（浏览器实录，约 100 秒，带字幕）。

## 用户与核心问题

面向需要核对投资假设的个人研究者和初级分析师。常见问题不是“没有一段总结”，而是结论缺少边界：没有统一时间和口径，支持材料比反向材料更容易被选中，代理指标被误写成因果，后续证据变化后原判断仍被沿用。

本产品围绕一项研究展开：**提出命题 → 澄清、修订 → 验证 → 查看证据与冲突 → 比较新年度 → 追问 → 保存或导出**。

## 快速运行

需要 Node.js 22.18+（本次实际使用 26.5.0）、npm 与网络。不需要 API 密钥。

```bash
npm ci
npm run dev
```

打开终端显示的本机地址，默认 `http://localhost:5173`。

```bash
npm test
npm run typecheck
npm run build
npm start
```

`npm test` 为确定性研究规则测试；`npm run build` 生成 Cloudflare Worker 部署产物。`npm start` 启动构建后的本地 Worker。保留 Sites 的构建集成；若部署到新的 Sites 项目，必须使用新的项目身份替换 `.openai/hosting.json`，不要向本仓库原项目直接发布。

浏览器回归脚本见 `tests/e2e.mjs`，通过 `PLAYWRIGHT_MODULE_PATH` 指定已安装 Playwright 模块，通过 `PLAYWRIGHT_BROWSER_EXECUTABLE_PATH` 指定 Chromium/Chrome；默认使用 `playwright` 包和其 Chromium。测试前启动开发服务器，并设置 `APP_URL`（缺省为 http://localhost:5173）。

## 建议体验路径（两分钟）

1. 使用默认命题：“比亚迪2024年盈利改善主要来自主营业务，而非一次性收益。”
2. 点击“拆解命题”，把主要贡献阈值修订为 70%，确认年度口径后验证。
3. 查看部分支持的结论：扣非利润增量解释约 83.42% 的归母净利增量；不是主营因果的充分证明。
4. 筛选反向证据：经营现金流下降 21.37%。打开来源，定位至年报 PDF 第 11 页。
5. 查看无法验证项与会计口径冲突；追问“扣非等于主营吗？”。
6. 打开年度比较并用 2025 年重验：归母和扣非利润下降，盈利改善前提被反对。
7. 添加备注，保存研究；刷新后在研究任务中恢复。导出 JSON 包含命题、证据、来源和备注。
8. 原始材料库可以重新下载固定白名单中的原文并校验 SHA-256；异常时保留历史快照并报错。

## 设计与实现

视觉方向是安静的研究台：纸白底、深绿色侧栏、低饱和证据状态色。证据不以“多数票”生成结论，未知不隐藏。使用覆盖度而不是无依据的置信百分比。桌面和移动端均可操作。

- `components/research-app.tsx`：研究流程、来源详情、对比、任务与导出。
- `lib/research.ts`：输入范围、规则拆解、财务计算、证据构建与有界追问。
- `data/financials.json`：已核验原始金额、币种、期间、来源家族、页码和文件指纹。
- `app/api/research/route.ts`：校验请求并执行确定性研究规则。
- `app/api/sources/route.ts`：固定来源下载、超时/大小限制与内容哈希验证。
- `tests/`：规则回归与浏览器测试。
- `docs/`：AI 使用记录、测试说明、数据说明与演示脚本。

技术栈：React + TypeScript + Vinext/Vite，运行于 Cloudflare Workers。任务持久化使用浏览器 localStorage；当前不需要数据库。个人研究结果不写入共享服务器。

## AI 的角色

开发阶段使用 Codex 辅助需求拆解、代码实现、资料定位与文档整理，并将财务数字逐项回到原始 PDF 校验。运行阶段暂不调用模型：三类命题分流、六项问题拆解和有限追问为规则生成，所有已显示财务比率由程序计算。

后续模型应负责语义澄清、检索计划和有引用的解释；数值、期间、来源存在性和断言边界仍由确定性代码校验。建议模型输出严格结构：`claim / question / evidence_ids / stance / reasoning / limitations / change_conditions`，只允许引用服务端已取得的证据 ID。无来源断言应降级为无法验证。此设计**尚未接入、未实测**；没有把未来方案计入已完成能力。

## 数据与证据边界

当前仅覆盖比亚迪 2023–2025 完整年度报告，研究期间可选 2024 或 2025。2023 是比较基期。已知 2026 半年报存在，但未纳入本版；不得称本版数据为最新财报或当前投资观点。

数据来自公司原始披露，托管于巨潮资讯、港交所和深交所。四份文件属于三个年度证据家族；2024 巨潮与港交所为同一报告的转载。所有财务证据仍以同一发行人披露为基础，不能声称获得第三方独立验证。

- 金额底层统一人民币元，展示为亿元；附注中的千元需要乘 1,000。
- 2024 归母净利 402.54 亿元、扣非 369.83 亿元、经营现金流 1,334.54 亿元。
- 增量占比 = (36,982,887,000 − 28,462,432,000) / (40,254,346,000 − 30,040,811,000) = 83.42%。
- 归母净利没有正增量时，不计算正向增长贡献率。
- 2023 汽车相关毛利率使用 2024 年报重分类后的 21.02%，与 2024 年的 22.31% 比较，增加 1.29 **个百分点**。
- 扣非不等于主营，也不等于剔除所有补助。2024 全部计入损益补助约 106.60 亿元，列入非经常性损益的补助约 37.81 亿元，二者口径不同。

页码与原文链接见数据文件、产品来源面板和 `docs/DATA.md`。快照是人工核对的结构化提取，不是在线自动抽取。核验原文状态只检查同一 PDF 是否变化，不搜索新的披露。

## 错误与安全

请求长度、参数类型、期间和阈值有校验；其他公司、季度、当前时点和未覆盖表述不能套用样例证据。规则语言理解能力有限，不支持任意自然语言命题。

来源接口只接受固定来源 ID，不接受用户 URL；禁止跟随重定向，限制 18 秒及 24MB；HTTP、非 PDF、哈希变化与网络超时分别处理。浏览器请求校验 Origin；React 转义用户文本。尚未针对公共高并发场景部署全局配额或防滥用系统，因此默认私有。

个人研究备注只在本机浏览器保存，清除浏览器存储会删除任务；无跨设备同步。保存失败会提示导出。来源检查状态为本次会话状态。页面不提供内幕信息、收益保证、个性化仓位或交易指令；关键词边界规则不等于完整合规审查。
